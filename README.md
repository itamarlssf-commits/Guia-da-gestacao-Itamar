## Como compartilhar com suas pacientes

### 1. Ative o GitHub Pages (apenas uma vez)

1. Acesse: **Settings** (engrenagem, no topo do repositório)
2. No menu lateral esquerdo, clique em **Pages**
3. Em *Source*, selecione **GitHub Actions**
4. Clique em **Save**

### 2. Acesse o link público

Após ativar e o deploy concluir (≈ 1 minuto):

**`https://itamarlssf-commits.github.io/meuclaudio/`**

Compartilhe esse link com suas pacientes por WhatsApp, e-mail ou QR Code.

### 3. Atualizar o conteúdo

Para atualizar qualquer informação no guia, edite os arquivos e faça commit — o site é atualizado automaticamente em ≈ 1 minuto.
